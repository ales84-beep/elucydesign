# ELUCY design konfigurator majic

To je staticka spletna stran/prototip konfiguratorja majic za ELUCY design.

## Zagon prek GitHub Pages

V GitHub repository nalozi vsebino te mape `outputs` v root repozitorija.
Na vrhu repozitorija morajo biti:

- `index.html`
- `konfigurator.html`
- `assets/`
- `preview-server.py`
- `start-preview.bat`
- `CODEX_NADALJEVANJE.md`

Nato v GitHub nastavitvah vklopi Pages:

- Settings
- Pages
- Deploy from a branch
- Branch: `main`
- Folder: `/root`

## Pomembno

Za nadaljevanje dela v Codexu odpri datoteko `CODEX_NADALJEVANJE.md`.
Tam je povzetek projekta, trenutne funkcije, struktura datotek in opombe za naslednje delo.
